# English Premier League (EPL) Data Analysis – Power BI

## 📌 Project Overview

This project focuses on analyzing English Premier League (EPL) match data using Microsoft Power BI. It explores league statistics, team performance, home vs away comparisons, and season-wise analysis to identify patterns and generate meaningful insights.

The analysis covers two EPL seasons:
- 2024/25
- 2025/26

Interactive dashboards and DAX measures are used to transform raw match data into meaningful visual insights.

## 🎯 Project Objectives

- Analyze overall Premier League performance.
- Evaluate individual team performance.
- Compare home and away match results.
- Analyze differences between two EPL seasons.
- Identify patterns in goals, match results, and team statistics.
- Develop interactive dashboards for data-driven analysis.

## 📂 Dataset Description

The project uses two CSV datasets containing English Premier League match statistics.

| Dataset | Season |
|---|---|
|EPL_2024_2025.csv | 2024/25 |
|EPL_2025_2026.csv | 2025/26 |

### Dataset Details

- Total Match Records: 760
- Total Columns: 151
- Data Format: CSV

The datasets contain match results, goals, shots, shots on target, corners, fouls, yellow cards, red cards, and other football match statistics.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Analytical calculations and measures
- **CSV** – Dataset format

## 📊 Dashboard Pages

### 1. League Overview
Provides an overview of EPL statistics and key performance indicators to understand the overall performance of the league.

### 2. Team Performance
Analyzes team-level performance through match results, goals, and other performance indicators.

### 3. Home vs Away Comparison
Compares home and away match performances to identify differences in results and match statistics.

### 4. Season Comparison
Compares the 2024/25 and 2025/26 seasons to explore changes and trends in league performance.
